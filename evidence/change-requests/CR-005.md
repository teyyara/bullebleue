# CR-005 — Official logo, activity photography and logo-derived colour direction

**Received:** 2026-11-03  
**Status:** COMPLETE IN LOOP 010–011.

## User direction

The user supplied the transparent association logo and documentary activity photos in `assets/`, reports that the owner authorised use of Facebook-page assets, and requested that the provisional BB mark be replaced, relevant photos be placed and the entire site's colour direction derive from the logo.

## Implementation

- Loop 010 replaced both provisional marks on all six pages with the official local transparent PNG.
- Loop 010 placed one close-up activity photo on the homepage and three on the activities page; people-forward photographs showing identifiable participants, including children, remain unpublished pending confirmation of image-specific participant/guardian consent.
- Loop 011 directly sampled the uploaded original transparent PNG (1052×1024 RGBA).
- The old warm clay/ochre palette was retired. Shared CSS tokens, page theme metadata and the SVG favicon now use the sampled blue family.
- Long-reading surfaces use documented pale tints derived from the logo's highlights.
- CSS, favicon, page metadata, validator, README, product contract and visual asset register were updated.

## Palette method and evidence

An alpha-weighted eight-cluster colour analysis was run on a deterministic 120,000-pixel sample of visible source pixels (alpha > 0.15). Representative hex values are nearest actual source pixels to each cluster centre; visible-pixel shares are approximate and rounded. Full sampling metadata is recorded in `evidence/visual/logo-palette.json`.

Dominant clusters: primary blue `#1C60CF` (23.3%), clear blue `#2084DE` (21.4%), cobalt `#1642A5` (14.9%), icy blue `#9DC0EA` (13.2%), deep navy `#06195E` (8.1%), sky blue `#4EABEC` (7.7%), pale highlight `#D3DEF0` (6.8%) and steel blue `#587ABA` (4.6%).

## Remaining verification boundaries

Source assertions, responsive CSS source and contrast pairs are checked. A full rendered browser review of all six pages and cross-browser/assistive technology testing remain separate tasks. No production deployment was performed.
