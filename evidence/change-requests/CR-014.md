# CR-014 — Transparent character cut-outs from drawings 6–9

**Received:** 5 November 2026  
**Status:** Adopted and implemented in Loop 022

## Request
Prepare individual transparent character cut-outs from the four supplied child-made drawings currently used as complete artwork in the homepage story collage. Preserve the original artwork and the full drawing sheets in the Jouer/créer collage.

## Implementation
- Created 20 individually addressable SVG cut-outs with hand-traced alpha silhouettes: six from drawing 6, four clearly drawn characters from drawing 7, one from drawing 8 and nine from drawing 9.
- Each cut-out uses the corresponding original JPEG as its image source; the SVG clipping path removes the photographed paper/background without redrawing or recolouring the artwork.
- Drawing 7's pasted football photograph and cropped edge fragment are deliberately excluded from the drawn-character set.
- Positioned the 20 figures in four compact, original-aspect-ratio groups in the sticky homepage artwork. Removed the paper-card border/background from those four groups and retained a restrained soft shadow.
- Kept all four full original JPEGs in the Jouer/créer collage; no documentary-photo distribution or copy was changed.
- Added structural checks for cut-out count, source preservation and clipping paths; added browser checks for rendering and transparency styling.

## Boundaries
No new people, quotations, photos, or factual claims were introduced. No paid dependency, external image service or deployment was added. The supplied artwork remains unaltered as the pixel source.

## Acceptance
Pending the Loop 022 Python, Node and Playwright workflow run and desktop/mobile screenshot inspection.
