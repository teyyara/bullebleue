# CR-017 — Cross-browser responsive validation

**Received:** 6 November 2026  
**Status:** Adopted and implemented — Loop 025 complete

## Request / objective
Close the automated Firefox and WebKit compatibility gap while preserving the existing responsive checks and screenshots.

## Implementation
- Added a `BROWSER_ENGINE` environment selector to `tests/test_browser.py` supporting Chromium, Firefox and WebKit.
- Updated GitHub Actions to install all three Playwright engines and run the same responsive suite separately in each engine.
- Kept the full 9-page / 5-width matrix and existing route, image, overflow, navigation, keyboard, About, Actualités, Contact, Adhérer, legal, sticky-story, reduced-motion, no-JavaScript and browser-error checks active in every engine.
- Preserved only Chromium's 30 screenshot files in the visual-review artifact to avoid three copies of the same image set.
- Made computed-style serialization engine-neutral and added one diagnostic retry for transient local route responses, while retaining a strict HTTP 200 requirement.

## Results
- Python structural validator: PASS.
- Node syntax/menu/story/reduced-motion tests: PASS.
- Playwright Chromium: PASS — 9 pages × 5 viewports = 45 combinations.
- Playwright Firefox: PASS — 9 pages × 5 viewports = 45 combinations.
- Playwright WebKit: PASS — 9 pages × 5 viewports = 45 combinations.
- Total: 135 page/viewport combinations; no horizontal overflow, missing local image, unexpected external request, page error or console error.
- GitHub Actions: [42237625691](https://github.com/teyyara/bullebleue/actions/runs/42237625691).
- Screenshot artifact: [13511744695](https://github.com/teyyara/bullebleue/actions/runs/42237625691/artifacts/13511744695), 30 Chromium captures; About desktop/mobile opened and reviewed.

## Coverage boundary
Playwright WebKit on Ubuntu is not native Safari on macOS/iOS. Real Safari, screen-reader, physical-device, Lighthouse, ZAP and hosted checks remain open. No production deployment.
